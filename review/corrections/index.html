The corrections register for Signal to Decision. Every correction issued, dated, newest first.

This page lists every correction Signal to Decision has issued, newest first. Nothing is removed from it once published.

The register is empty. It has been open since 19 July 2026.

That is the honest state, and publishing it while empty is deliberate. A corrections page that appears on the day of the first correction is not a standing practice. This one exists first.

How corrections work here

If Signal to Decision publishes a statement of fact that is wrong, the correction runs at the top of the next edition, above the first story. Not in a footer, and not only on the web.

The correction issues on every surface the error reached. If it went out on this site, in the LinkedIn edition, in the video and in the audio, it is corrected on every one of them.

The note names what was wrong, not only what is now right, and it says how the error happened. The word used is "correction". Not "update", not "clarifies". Where the archive page carried the error, that page is corrected and an amendment note is appended to it, so the record shows both the fix and the fact that a fix was needed.

Something published accurately that later changes is not a correction. It gets a dated note saying what changed and when.

Telling me about an error

If you think something here is wrong, tell me and I will check it against the primary source. If it is wrong, it gets corrected on this page and in the next edition. If it is right, I will show you the source.
